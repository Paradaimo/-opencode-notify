# opencode notify

Push-уведомления на телефон когда opencode завершает генерацию, падает с ошибкой или просит доступы. Работает через GitHub: плагин на ПК пишет события в ваш **приватный** репозиторий-«ящик», приложение на Android опрашивает его каждые 30 секунд.

Сеть нужна только к `api.github.com` (443 порт). SMTP/Telegram не используются.

## Что внутри

| Файл | Назначение |
|---|---|
| `opencode-notify.apk` | Приложение для Android |
| `notify.mjs` | Плагин opencode (пишет события в GitHub) |
| `README.md` | Эта инструкция |

## Настройка с нуля

### 1. GitHub: ящик и токен

1. Войдите на <https://github.com>.
2. Создайте репозиторий: **New repository** → имя, например `opencode-events` → **Private** → Create. Пустой, без README. Это «почтовый ящик» — сюда падают события с названиями ваших чатов, поэтому только приватный.
3. Создайте токен: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:
   - *Repository access* → **Only select repositories** → выберите ящик;
   - *Permissions* → **Contents** → **Read and write** (остальное можно не давать);
   - сгенерируйте и **скопируйте токен** (повторно он не показывается).

### 2. ПК с opencode

1. Скачайте `notify.mjs` из этого репозитория:
   <https://raw.githubusercontent.com/Paradaimo/-opencode-notify/main/notify.mjs>
2. Скопируйте в папку конфига opencode:
   - Windows: `C:\Users\<вы>\.config\opencode\`
   - Linux/macOS: `~/.config/opencode/`
3. Запустите opencode один раз — плагин сам создаст рядом файл `notify-github.json` (шаблон). Заполните его:
   ```json
   {
     "owner": "ваш-логин-github",
     "repo": "opencode-events",
     "token": "ваш_токен",
     "path": "events.json",
     "maxEvents": 100
   }
   ```
4. В `opencode.json` (та же папка) добавьте плагин в массив `plugin`:
   ```json
   {
     "plugin": [
       "file:///C:/Users/<вы>/.config/opencode/notify.mjs"
     ]
   }
   ```
   (если массив уже есть — просто добавьте строку с запятой).
5. Перезапустите opencode.

### 3. Телефон (Android 8+)

1. Скачайте и установите `opencode-notify.apk` (Android попросит разрешить «Установка из неизвестных источников» — разрешите только для браузера/файлового менеджера).
2. Откройте приложение «opencode notify», разрешите уведомления.
3. Введите:
   - **URL фида событий**: `https://raw.githubusercontent.com/<ваш-логин>/<ящик>/main/events.json`
   - **GitHub токен**: токен из шага 1 (обязателен — без него API GitHub отдаёт не больше 60 запросов в час и уведомления запаздывают).
4. Нажмите **«Начать слушать»**; в системном диалоге разрешите «Не оптимизировать батарею».
5. Закрепите приложение в недавних: свайп вниз по его карточке → замок. Иначе Android может замораживать опрос, и задержка вырастет до нескольких минут.

## Как это выглядит

- **«opencode · готово»** — `Название чата · Готово · @субагент: задача · ПК · папка`
- **«opencode · ошибка»** — `Название чата · Ошибка: <текст> · ...`
- **«opencode · нужны доступы»** — `Название чата · Нужны доступы: <что> · ...`

Субагенты отдельными уведомлениями не дублируются: их результат приписывается к завершению основного чата. Все события дублируются в **Журнал** внутри приложения (кнопка «Очистить» рядом), поэтому утром можно пересмотреть, что происходило.

## Замечания

- Задержка уведомления — до ~30 секунд (период опроса) плюс время, за которое GitHub обновляет файл.
- Если телефон пишет `ОШИБКА: http 401/403` — токен не тот или у него нет доступа к ящику.
- Файл `events.json` хранит последние 100 событий (настраивается в `notify-github.json`).
- Обновление APK: просто установите новый файл поверх старого; журнал и настройки сохраняются.
